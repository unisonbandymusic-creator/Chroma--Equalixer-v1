# Chroma-Equalizer (VST3) by Him'z DSP
Linear-phase 5-band EQ with live Mud/Harsh analysis. Built with JUCE 8.
Build: push to GitHub -> Actions tab -> "Build VST3" -> download the artifact (Windows / Mac).
Install: Windows -> C:\Program Files\Common Files\VST3 ; Mac -> ~/Library/Audio/Plug-Ins/VST3
Mac (unsigned): run  xattr -cr ~/Library/Audio/Plug-Ins/VST3/Chroma-Equalizer.vst3
